# Kepenk v0.1.0 — release notes draft

> Draft: do not publish or tag until the PyPI distribution name and publishing ownership are confirmed.

Kepenk v0.1.0 is the first public alpha of a deterministic approval and audit gate for AI coding agents. It places a local policy decision between an agent and a side-effecting action and returns `allow`, `approval`, or `deny`.

## Highlights

- provider-neutral YAML policy engine
- fail-closed policy loading and validation
- `kepenk validate`, `check`, `run`, `approve`, and `verify-audit` workflows
- hash-chained JSONL audit records
- safe subprocess execution with `shell=False`
- JSON Schema for editor validation and autocomplete
- Codex-oriented wrapper examples while keeping the core provider-neutral
- reusable GitHub Action
- tested PowerShell and Windows policy examples
- reproducible wheel and source-distribution checks

## Supported runtime

- Python 3.11 and 3.13 are continuously tested on Ubuntu and Windows.
- The package metadata also permits Python 3.12.

## Security boundary

Kepenk is an approval and policy layer, not a sandbox. It should be combined with operating-system isolation, least-privilege credentials, protected branches, and normal software supply-chain controls.

## Installation after publication

```bash
python -m pip install kepenk-gate
kepenk --help
kepenk init
kepenk validate
```

The installation command remains provisional until the PyPI distribution name is confirmed.
