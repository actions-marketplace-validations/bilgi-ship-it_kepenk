# Kepenk v0.2.1

**Release date:** 2026-07-31

Kepenk v0.2.1 is a focused portability patch for the composite GitHub Action.

## Fixed

The Action no longer configures consumer-repository pip caching. In v0.2.0, that cache setting caused setup-python to fail before policy evaluation when the target repository had no Python dependency file.

The failure was reproduced by the public Ustaca AI npm/Turborepo founding-team pilot and fixed without requiring the consumer repository to become a Python project.

## Compatibility

Action inputs, outputs, decision exit codes, the pinned setup-python revision, the Python runtime, policy format, and package interfaces remain compatible with v0.2.0.

## Verification

The release source branches from v0.2.0 and excludes current v0.3 work. The annotated `v0.2.1` tag resolves to the verified maintenance commit. The published wheel and source distribution were downloaded again, installed in clean environments, and passed all three public command-entry-point smoke tests.

The public Ustaca AI pilot also passes when pinned to `v0.2.1`.

## Security boundary

Kepenk remains a policy and approval layer rather than a sandbox. This patch changes only GitHub Action setup portability.

Public PyPI publication remains separate and was not performed by the GitHub Release workflow.
