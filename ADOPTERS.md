# Kepenk adopters

This file lists public repositories that use Kepenk and have agreed to be listed.

Kepenk does not use telemetry or automatic user counting. Every entry needs a public repository link and a public evidence link showing the integration.

## Entry requirements

Each row must include:

- a public repository;
- a public link showing a Kepenk policy, workflow, hook, or adapter;
- the integration type;
- maintainer consent;
- the verification date in `YYYY-MM-DD` format.

Stars, forks, downloads, and unsupported statements are not adopter evidence.

Use the adopter pull-request template to add an entry. A maintainer may request removal through an issue or pull request. See [the adoption guide](docs/adoption.md) and [the case-study template](docs/case-study-template.md).
